Dash0 is an OpenTelemetry-native observability platform for engineering teams who want full visibility into logs, metrics, traces, profiles and events without operating complex pipelines or proprietary agents. Founded in 2023 (Series B, $110M, 2026), Dash0 ingests OTLP natively, correlates signals automatically, and offers dashboards, PromQL-based alerting, SLOs, synthetic and website monitoring, a service map, transparent cost controls, and Agent0 AI SRE agents. Its public API is a 108-operation OpenAPI 3.1 surface (regional AWS/GCP hosts) covering Observability-as-Code (dashboards, check/recording/ sampling rules, views, spam filters, notification channels, synthetic checks, automations), telemetry query (spans/logs/traces/SQL), and a Prometheus HTTP API, plus an OAuth-protected MCP server, a Go CLI and a Terraform provider.

**Areas:** Observability · OpenTelemetry · Monitoring · Logs · Metrics · Tracing · APM · Prometheus · DevOps · Company · A2A

## How this profile is made
